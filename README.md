# Naditha Gallella — Distributed Systems & Cloud Infrastructure Portfolio

> Cloud, DevOps & Systems Infrastructure Engineer personal portfolio website showcasing AWS cloud migrations, Hyper-V virtualization, network firewall security, and embedded IoT hardware.

---

## ⚡ Tech Stack & Architecture

- **Core Framework**: React 19, TypeScript, Vite 6
- **Styling**: Tailwind CSS, PostCSS, Custom Monospace Design System
- **3D & Graphics**: Three.js (rotating wireframe Earth globe & 3D systems shelf)
- **Icons**: Lucide React
- **Hosting & CI/CD**: Static bundle ready for AWS S3 + CloudFront, Cloudflare Pages, or GitHub Pages

---

## 🚀 Key Features

- **Hero Typing Engine**: Dynamic typewriter animation cycling through 50 simplified systems engineering terms with random non-repeating shuffle and custom glowing cyan cursor.
- **Featured 3D Systems Archive**: Interactive curved 3D project spine showcase with category filters and deep-dive architecture modal breakdowns.
- **Hobby Lab Showcase Reel**: Interactive engineering widgets featuring YouTube AWS tutorials, ESP32 PCB hardware revisions, 4-phase AWS migration runbook tabs, and Linux kernel sysctl admin consoles.
- **Dedicated Blog**: Technical article search, domain filtering, and architecture postmortems.
- **Full Breakpoint Adaptability**: Responsive design optimized for desktop (`1440px`), tablet (`768px`), and mobile (`390px`).
- **Hardened Security**: Protected against XSS, input injection, and reverse tabnabbing (`rel="noopener noreferrer"`).

---

## 🛠️ Local Development

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/Nadithaa/Naditha_personal_profile.git
cd Naditha_personal_profile

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
# Build production bundle
npm run build

# Preview production build locally
npm run preview
```
